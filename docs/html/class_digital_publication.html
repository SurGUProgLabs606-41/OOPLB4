Подробное описание

Промежуточный класс электронных изданий.

Содержит характеристики электронного издания. От него наследуются классы EBook и HybridBook.

Использует виртуальное наследование от Publication, чтобы избежать дублирования базового объекта при множественном наследовании в классе HybridBook.
