Подробное описание

Объявление абстрактного базового класса Publication.

Класс Publication представляет общий интерфейс библиотечного издания.

Реализует следующие требования лабораторной работы:

Пункт 1. Начальный уровень иерархии наследования.

Пункт 2. Абстрактный базовый класс. Содержит чисто виртуальные функции getTitle(), getISBN() и printInfo().

Пункт 3. Объявляет виртуальную функцию isDigital(), которая имеет реализацию по умолчанию в Publication.cpp.

Пункт 4. Содержит конструктор копирования и оператор присваивания.

Пункт 5. Содержит статические поля totalCount и digitalCount, а также статические методы getTotalCount(), getDigitalCount() и findByISBN().

Пункт 6. Обеспечивает полиморфную работу через указатели и ссылки на базовый класс.

Пункт 8. Объявляет дружественную функцию printPublication().
