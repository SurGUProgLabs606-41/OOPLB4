Подробное описание

Объявление промежуточного класса PrintedPublication.

Класс представляет печатное библиотечное издание.

Реализует следующие требования лабораторной работы:

Пункт 1. Второй уровень иерархии наследования. Наследуется от Publication с использованием виртуального наследования.

Пункт 3. Переопределяет виртуальную функцию printInfo() для вывода характеристик печатного издания.

Пункт 4. Объявляет конструктор копирования и оператор присваивания.

Содержит общие характеристики печатных изданий: количество страниц и издательство.
