Подробное описание

Промежуточный класс печатных изданий.

Содержит дополнительные характеристики печатной публикации. От него наследуются классы Book и Magazine.

Используется виртуальное наследование от Publication, чтобы при множественном наследовании не создавать несколько экземпляров базового класса. В дальнейшем класс HybridBook наследуется одновременно от Book и DigitalPublication. Оба пути наследования ведут к Publication. Виртуальное наследование позволяет избежать появления двух отдельных экземпляров Publication внутри одного объекта HybridBook.
