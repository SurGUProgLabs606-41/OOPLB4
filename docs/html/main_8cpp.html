Подробное описание

Тестовая программа для проверки иерархии библиотечных изданий.

Демонстрирует выполнение следующих требований лабораторной работы:

Пункт 6. Полиморфизм через массив указателей Publication*.

Пункт 9:

  • создание объектов всех конкретных классов;
  • полиморфный вызов виртуальной функции printInfo();
  • использование статических счётчиков;
  • поиск издания по ISBN;
  • проверка конструктора копирования;
  • проверка оператора присваивания;
  • проверка независимости копии от оригинала;
  • обработка исключений;
  • проверка множественного наследования через HybridBook;
  • вызов дружественной функции printPublication().

Пункт 11. Загрузка начальной информации об изданиях из внешнего текстового файла publications.txt.

Программа используется для проверки статической и динамической библиотек с одинаковым клиентским кодом.

Демонстрация полиморфизма.

Все элементы массива имеют тип указателя Publication*, однако фактически указывают на объекты разных производных классов.

При вызове printInfo() автоматически выбирается реализация соответствующего фактического типа объекта.

Вывод статистики по созданным объектам.

getTotalCount() возвращает общее количество объектов Publication, а getDigitalCount() — количество электронных изданий.

ISBN для проверки поиска издания.

Используется статический метод findByISBN().

Поиск издания по ISBN.

Метод findByISBN() выполняет поиск среди зарегистрированных объектов и возвращает указатель на найденное издание. Если издание отсутствует, возвращается nullptr.

Проверка конструктора копирования и оператора присваивания.

Создается исходный объект HybridBook, затем его копия с помощью конструктора копирования и отдельный объект, которому присваиваются данные оригинала.

После этого оригинал изменяется. Копия и присвоенный объект должны сохранить прежние данные.

Создание копии объекта с помощью конструктора копирования.

Создание объекта для проверки оператора присваивания.

Изменение исходного объекта.

Проверяет, что ранее созданные копия и присвоенный объект сохраняют собственные значения.

Демонстрация дружественной функции.

Функция printPublication() получает ссылку на базовый класс Publication и вызывает метод printInfo().

Поскольку функция объявлена дружественной в Publication, она имеет доступ к закрытым и защищенным членам этого класса.

Освобождение динамически выделенной памяти.

Каждый объект изданий удаляется через указатель Publication*. Виртуальный деструктор базового класса обеспечивает корректное уничтожение объектов производных классов.

После удаления объектов их деструкторы обновляют счетчики и удаляют соответствующие записи из реестра Publication.
