Подробное описание

Абстрактный базовый класс библиотечного издания.

Хранит общую информацию об издании: название и ISBN. Также содержит общие счётчики созданных объектов и статический массив для регистрации существующих объектов.

Класс является абстрактным, поскольку содержит чисто виртуальные методы getTitle(), getISBN() и printInfo().

Деструктор базового класса.

Удаляет указатель на текущий объект из массива registry и уменьшает общий счётчик объектов.

Виртуальность деструктора необходима для корректного удаления объектов производных классов через указатель на базовый класс.
