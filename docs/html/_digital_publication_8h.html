Подробное описание

Объявление промежуточного класса DigitalPublication.

Класс представляет электронное библиотечное издание.

Реализует следующие требования лабораторной работы:

Пункт 1. Второй уровень иерархии наследования. Наследуется от Publication с использованием виртуального наследования.

Пункт 3. Переопределяет виртуальную функцию isDigital(), возвращая true для электронных изданий.

Пункт 4. Объявляет конструктор копирования и оператор присваивания.

Пункт 5. Участвует в подсчёте количества электронных объектов через статический счётчик digitalCount базового класса.

Содержит характеристики электронного издания: размер файла и формат.
