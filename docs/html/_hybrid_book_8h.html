Подробное описание

Объявление класса HybridBook — гибридной книги.

Реализует следующие требования лабораторной работы:

Пункт 1. Третий уровень иерархии наследования.

Пункт 3. Переопределяет виртуальные методы базового класса.

Пункт 4. Объявляет конструктор копирования и оператор присваивания.

Пункт 7. Демонстрирует множественное наследование от классов Book и DigitalPublication.

Использует виртуальное наследование через родительские классы, поэтому содержит только одну общую базовую часть Publication.

Объединяет характеристики печатной и электронной книги.
